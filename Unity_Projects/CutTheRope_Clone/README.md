## 🛠🔵 Techniques Used in Cut The Rope

- Physics-based jumping using Rigidbody2D and Collider2D
- Direction handling via Collision Detection and Physics Materials
- Velocity management and constant speed regulation
- Mobile Touch Input handling
- Pulsating UI animation for user engagement
- Score management system and UI integration
