## 🛠🐦 Techniques Used in Flappy Bird
- Physics-based movement using Rigidbody2D and AddForce() for jumping mechanics
- Time-based obstacle spawning
- Trigger-based score system
- Collision detection
- Basic UI and game over / restart management
